<center><img style="background-color: black; border-radius: 15px; padding: 12px" height="100" width="100" src="./public/images/icons/source-code-white.svg"/></center>

## Description
DarkThunder is a chat-app that have any convenient functionnalities to make Proffessional, Friend to Friend, Enterprise Level and School Purpose discussions more fluid and dynamique.

## Features
DarkThunder feature basique chat-app experience but not like others, the user interface and experience is disigned specialy for instant-discussions specifique needs.

With DarkThunder you can:

* Create and manage discussions for two and more users (also called members).
* Manage discussions members.
* Manage members permissions over a discussion (Read, Write, MOD).
* Use Regex to create special restriction pattern applied to any message in a discussion.
* Code syntaxe highlighting.
* Send files, images, sounds and videos to a discussions (Restricted).
* Real-time calls/video calls between 2 and a maximum of 250 discussion members.
